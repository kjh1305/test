# 공감 행정사사무소 홈페이지 시안

공감 행정사사무소(대표 행정사 ○○○) 홈페이지 시안입니다. 주소는 https://kjh1305.github.io/test/gonggam/ 입니다.

내용은 사무소 블로그 목록과 소개글, 받은 블로그 글 5개와 사진을 바탕으로 썼습니다. 자료가 없는 정확한 주소, 상담 시간, 행정사 등록번호, 사업자등록번호는 '채울 자리'로 표시해 두었습니다. 대표 인사말과 상담 절차는 예시 문안입니다.

사진(`assets/img`)은 블로그 이미지를 잘라 쓴 것입니다. 대표 사진은 블로그 배너에서, 업무 분야 사진 4장과 칼럼 표지 4장은 블로그 글에서 가져왔습니다. 원본 파일을 받으면 바꾸는 것이 좋습니다.

## 페이지

| 주소 | 내용 |
| --- | --- |
| `/` | 메인: 대표 사진과 서류에 도장이 찍히는 그림이 있는 첫 화면, 분야별 자주 받는 질문, 상담 원칙, 대표 행정사 약력, 상담 절차, 빠른 상담, 칼럼 표지 카드 4개 |
| `about/` | 사무소 소개: 대표 인사말(예시), 약력(학력·소속 포함), 사무소 정보, 오시는 길(동대문역사문화공원역 4번 출구, 지도는 채울 자리) |
| `services/` | 업무 분야 4개(분야별 사진): 출입국·비자, 출입국 사범심사·구제, 학교폭력·행정심판, 공장등록·인허가, 그리고 그 밖의 행정심판·민원행정 |
| `column/` | 칼럼: 블로그 글 24개를 분야별로 걸러 보기 (2026년 11월 9일 기준). 받은 글 4개는 그 글로, 나머지는 블로그 첫 화면으로 연결 |
| `contact/` | 상담 신청 폼 (입력 확인만 하고 실제 전송은 없음) |

`contact/?area=school`처럼 분야를 붙이면 상담 신청 폼에서 그 분야가 미리 선택됩니다(`visa`, `review`, `school`, `permit`, `etc`).

## 구조

- `src/content.mjs`: 모든 문구
- `src/art.mjs`: 아이콘, 서류 그림, 도장
- `src/layout.mjs`: 헤더, 모바일 메뉴, 푸터, 고정 상담 바
- `src/pages.mjs`: 페이지별 본문
- `build.mjs`: 위 내용으로 HTML을 만듭니다
- `assets/css/site.css`, `assets/js/site.js`: 디자인과 화면 동작
- `assets/img`: 블로그에서 가져온 사진 (WebP)
- `assets/fonts`: Pretendard, Noto Serif KR (모두 SIL OFL, 라이선스 파일 포함)

## 고치는 방법

1. `src/content.mjs`의 문구를 고칩니다.
2. 이 폴더에서 `node build.mjs`를 실행합니다 (Node 18 이상, 설치할 패키지 없음).
3. 만들어진 HTML과 함께 커밋해서 `main`에 올리면 GitHub Pages에 반영됩니다.

시안이라 검색엔진 수집은 막아 두었습니다(`noindex`).
