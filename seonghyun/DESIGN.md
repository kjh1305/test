# DESIGN.md · 주식회사 성현 시안

방화셔터 제조사 홈페이지. 보는 사람은 건설사·설계사무소·감리 담당자와 셔터 시공·수리업자입니다. 이들이 찾는 것은 품질인정, 규격, 서류, 전화번호입니다.
느낌은 **공장처럼 단단하고 정직하게**, 꾸밈보다 정보가 먼저입니다.

업체는 지금 홈페이지(seonghyun.co.kr)의 남색 + 파란색이 마음에 들지 않는다고 했습니다. 그래서 이 시안에서는 남색과 파란색을 쓰지 않습니다.
실제 사이트 디자인 라이브러리(UXKIN)는 연결하지 않았습니다. 이 방향은 업체의 지금 사이트, 받은 현장 사진, 아래 원칙만으로 정했습니다.

## 1. 색

밝은 바탕(흰색 + 모래색)이 기본이고, 짙은 색은 따뜻한 숯색입니다. 강조는 방화 호박색 한 가지입니다.

| 토큰 | 값 | 역할 |
| --- | --- | --- |
| `--ink` | `#221E1A` | 본문·제목 글자 |
| `--ink-2` | `#4A443E` | 보조 글자 |
| `--muted` | `#6B6560` | 설명·라벨 (흰 바탕 5.7:1, `--sand-2` 4.8:1. `--sand-3` 위에는 쓰지 않음) |
| `--line` / `--line-2` | `#E4DFD8` / `#CFC8BF` | 구분선, 테두리 |
| `--sand` / `--sand-2` / `--sand-3` | `#F7F5F2` / `#EFEBE5` / `#E7E1D8` | 번갈아 쓰는 섹션 바탕, 그림 바탕 |
| `--char` / `--char-2` / `--char-3` | `#24201C` / `#1A1714` / `#3A332C` | 짙은 바탕(푸터, 아래 패널, 404). 남색 대신 |
| `--char-text` | `#BDB3A7` | 짙은 바탕 위 보조 글자 (7.8:1) |
| `--amber-btn` | `#B85C00` | **주 색**: 흰 글자를 얹는 버튼, 포커스 테두리 (흰 글자 4.6:1) |
| `--amber-ink` | `#A35200` | 흰·모래색 바탕 위 강조 글자와 링크 |
| `--amber` | `#E8820C` | 장식만: 선, 진행 막대, 짙은 바탕 위 큰 숫자 (글자에 쓰지 않음) |
| `--amber-light` | `#F5A23A` | 짙은 바탕 위 강조 글자 |
| `--amber-50` / `--amber-100` | `#FFF3E3` / `#F6E2C6` | 옅은 강조 바탕 |
| `--ok` | `#2F6B3A` | 상태: 인정서 보유 배지 (흰 글자 6.4:1) |
| 대기 상태 | `--amber-50` 바탕 + `--amber-ink` 글자 | 시험 통과 · 인정서 발급 대기 |
| 판매 불가 | `--sand-2` 바탕 + `--muted` 글자 | 시험 전 · 판매 불가 |

다크 모드는 없습니다(제조사 소개 사이트, 인쇄·캡처가 잦음).

## 2. 글꼴

Pretendard 하나만 씁니다(본문·제목 공용, 사이트 안에 포함).

| 이름 | 크기 / 줄 간격 | 쓰는 곳 |
| --- | --- | --- |
| display | clamp(36px, 4.6vw, 60px) / 1.18, 700 | 첫 화면 제목 |
| h1 | clamp(32px, 3.6vw, 46px) / 1.25, 700 | 하위 페이지 제목 |
| h2 | clamp(26px, 2.6vw, 36px) / 1.3, 700 | 섹션 제목 |
| h3 | 18–22px / 1.4, 700 | 카드·항목 제목 |
| body-lg | 17–19px / 1.7 | 첫 화면·섹션 설명 |
| body | 16px / 1.7 | 본문 |
| small | 14–14.5px / 1.6 | 라벨, 캡션, 표 머리 |
| micro | 12.5–13px | 배지 |

- 숫자(전화, 인정번호, 규격)는 `tabular-nums`.
- **섹션 위 영어 작은 제목(COMPANY, PRODUCTS …)은 쓰지 않습니다.** 섹션은 한글 제목 + 한 줄 설명으로 시작합니다.

## 3. 간격

- 8px 기준: 4, 8, 12, 16, 24, 32, 48, 64, 96, 120.
- 섹션 위아래: PC 120px, 태블릿 96px, 휴대폰 72px.
- 내용 폭 최대 1280px, 좌우 여백 PC 40px · 휴대폰 20px. 본문 문단은 최대 680px.

## 4. 모양과 깊이

- 모서리: `--r` 6px(버튼 외 작은 것), `--r-lg` 16px(카드, 사진), 버튼은 둥근 알약(999px).
- 그림자는 하나: `0 24px 50px -36px rgba(34, 30, 26, .45)` (떠 있는 카드, 첫 화면 사진). 나머지는 1px 선으로 나눕니다.

## 5. 부품

- **버튼**: 주(호박색 바탕 + 흰 글자), 보조(흰 바탕 + `--line-2` 테두리), 조용한(`more`: 글자 + 화살표 + 밑줄). 마우스를 올리면 한 단계 진하게, 포커스는 3px 호박색 테두리. 카카오톡 버튼은 실선 테두리 + 노란 원.
- **링크**: `--amber-ink`, 마우스를 올리면 밑줄.
- **입력칸**: 흰 바탕, 1px `--line-2`, 포커스 시 호박색 테두리. 오류는 입력칸 아래 문장으로.
- **배지**: 상태 3가지(위 색 표)에 아이콘 + 글자. 색만으로 뜻을 나타내지 않습니다.
- **제품 목록**: 홈에서는 카드 대신 **표처럼 한 줄씩**(제품명 · 모델 · 내화 · 최대 개구부 · 상태). 같은 모양 카드를 늘어놓지 않습니다.
- **헤더**: 흰 바탕, 스크롤하면 아래 선. 하위 페이지는 머리 아래 바로가기 탭이 따라옵니다.
- **푸터**: `--char` 바탕.

## 6. 사진과 그림

- 실제 사진만 사진 자리에 씁니다. 받은 사진은 블로그 현장 사진(가로 966px)이라 화면 전체 배경에는 쓰지 않고 카드 크기로 씁니다.
- 한 페이지 안에서 같은 사진을 두 번 쓰지 않습니다.
- 사진이 없는 제품은 그림 카드 대신 **규격 판**(내화 시간, 최대 개구부 같은 큰 숫자)으로 보여 줍니다.
- 선 아이콘 한 세트(`src/art.mjs`의 `icon`, 1.6px 선)만 씁니다. 이모지는 쓰지 않습니다.
- 사진은 640px 작은 판을 함께 두고 `srcset`으로 화면에 맞는 크기를 받습니다.
