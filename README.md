# 마케팅 회사 홈페이지 시안

가상의 마케팅 회사 "플롯라인(Plotline)"을 기준으로 만든 여러 페이지짜리 홈페이지 시안입니다. 회사명, 고객사, 사례, 수치는 모두 가상입니다.

## 페이지

| 주소 | 내용 |
| --- | --- |
| `/` | 메인: 광고 소재 벽 첫 화면, 스크롤 연동 세 장면, 숫자, 서비스, 최근 사례, 인사이트 |
| `/about/` | 회사소개: 소개, 원칙, 숫자, 연혁, 팀 |
| `/services/` | 서비스 6개 상세, 일하는 방식, 자주 묻는 질문 |
| `/work/` | 포트폴리오 목록 (서비스·업종 필터, `?service=`/`?industry=` 주소 공유 가능) |
| `/work/<사례>/` | 사례 상세 9개 |
| `/insights/`, `/insights/<글>/` | 인사이트 목록과 글 4개 |
| `/contact/` | 문의 폼(검증만, 실제 전송 없음), 상담 절차, 약도 |
| `/404.html` | 없는 주소 안내 |

## 구조

- `src/data.mjs` — 회사 정보, 서비스, 사례, 글 등 모든 콘텐츠
- `src/creatives.mjs` — 가상 고객사 광고 소재 일러스트(SVG)
- `src/components.mjs` — 헤더, 푸터, 공통 레이아웃
- `build.mjs` — 위 내용으로 루트에 HTML 파일들을 만듭니다
- `assets/css/style.css`, `assets/js/main.js` — 디자인과 애니메이션, 필터, 폼
- `assets/fonts` — SUIT, 나눔손글씨 펜 (둘 다 SIL OFL, 자체 호스팅)

## 고치는 방법

1. `src/data.mjs`의 내용을 고칩니다. 실제 회사명은 `플롯라인`, `Plotline`을 검색해 바꾸면 됩니다.
2. `node build.mjs`를 실행합니다 (Node 18 이상, 설치할 패키지 없음).
3. 만들어진 HTML과 함께 커밋해서 `main`에 올리면 GitHub Pages에 자동으로 반영됩니다.

`404.html`은 저장소 이름(`/test/`) 기준 절대 경로를 씁니다. 저장소 이름이나 도메인이 바뀌면 `build.mjs`의 `notFound()`와 `src/data.mjs`의 `BASE_URL`을 같이 고쳐 주세요.

시안이라 검색엔진 수집은 막아 두었습니다(`noindex`).
