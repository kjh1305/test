# 겟스크린미(Getscreen.me) 한국총판 홈페이지 시안

겟스크린미 한국총판 홈페이지 리뉴얼 시안입니다. 주소는 https://kjh1305.github.io/test/getscreen/ 입니다.

내용은 공식 네이버 블로그의 소개글과 글 목록(2026년 11월 9일 기준)을 바탕으로 썼습니다. 요금은 블로그 글에 적힌 2026년 10월 13일 국내 가격표 기준입니다(Advanced, 상담원 3명, 연 30만원, 부가세 별도, 상담원당 동시 지원 세션 무제한). 상호는 아이비인포텍으로 넣었고, 자료가 없는 대표자, 주소, 사업자등록번호, 운영 시간, 다른 요금제, FREE 버전 제공 범위, 운영체제별 기능표, 보안 기능 상세, 내려받기 링크, 블로그 글별 주소는 '채울 자리'로 표시해 두었습니다. 개인정보 수집 동의 문구는 예시입니다.

실제 서비스 화면(dash.getscreen.kr)은 이 시안의 범위가 아닙니다. '무료로 시작하기'는 https://getscreen.kr 로 연결됩니다.

## 페이지

| 주소 | 내용 |
| --- | --- |
| `/` | 메인: 상담원 브라우저에서 고객 화면의 오류를 고치는 원격지원 화면, 지원 운영체제, 핵심 기능 6개, 연결 3단계, 요금 요약, 활용 분야, 최근 블로그 글 |
| `features/` | 기능: 웹 1:1 원격지원, 무인기기 상시접속, 고객사·부서별 그룹, PC와 모바일, 동시 지원 세션, 설치형 대시보드, 지원 운영체제 |
| `pricing/` | 요금: FREE, Advanced(연 30만원), 다른 요금제(채울 자리), 요금 질문 |
| `guide/` | 사용 방법: 빠른 지원 3단계, 무인 접속 3단계, 내려받기(채울 자리) |
| `support/` | 고객지원: 전화·카카오톡·이메일, 자주 묻는 질문 7개, 블로그 글 24개를 분류별로 걸러 보기 |
| `contact/` | 도입 문의 폼 (입력 확인만 하고 실제 전송은 없음) |
| `404.html` | 없는 주소 안내 |

`contact/?plan=advanced`로 들어오면 문의 내용에 Advanced 요금제가 미리 적히고 문의 유형이 '견적 문의'로 선택됩니다. `contact/?type=tech`처럼 유형만 고를 수도 있습니다(`intro`, `quote`, `tech`, `etc`).

첫 화면의 원격지원 그림은 10초 주기로 연결 → 오류 창 → 설정 변경 → 해결을 반복합니다. 화면 밖으로 나가면 멈추고, 기기에서 '동작 줄이기'를 켜면 해결된 장면으로 고정됩니다. 블로그 글은 글별 주소가 없어 모두 블로그 첫 화면으로 연결됩니다.

## 구조

- `src/content.mjs`: 모든 문구 (요금, 기능, 자주 묻는 질문, 블로그 글 목록 포함)
- `src/art.mjs`: 아이콘, 첫 화면의 원격지원 그림, 기능별 작은 화면
- `src/layout.mjs`: 헤더, 모바일 메뉴, 푸터, 상담 버튼
- `src/pages.mjs`: 페이지별 본문
- `build.mjs`: 위 내용으로 HTML을 만듭니다
- `assets/css/site.css`, `assets/js/site.js`: 디자인과 화면 동작
- `assets/fonts`: Pretendard (SIL OFL, 라이선스 파일 포함)
- `assets/og.png`: 링크 공유 이미지 (1200×630)

로고는 글자와 단순한 화면 아이콘으로 만든 임시 표시입니다. 실제 로고 파일을 받으면 바꿉니다.

## 고치는 방법

1. `src/content.mjs`의 문구를 고칩니다.
2. 이 폴더에서 `node build.mjs`를 실행합니다 (Node 18 이상, 설치할 패키지 없음).
3. 만들어진 HTML과 함께 커밋해서 `main`에 올리면 GitHub Pages에 반영됩니다.

시안이라 검색엔진 수집은 막아 두었습니다(`noindex`).
