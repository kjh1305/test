# 겟스크린미(Getscreen.me) 한국총판 홈페이지 시안

겟스크린미 한국총판 홈페이지 리뉴얼 시안입니다. 주소는 https://kjh1305.github.io/test/getscreen/ 입니다.

## 내용의 출처

공식 네이버 블로그(https://blog.naver.com/getscreenme)의 소개글, 글 목록(2026년 11월 9일 기준), 최근 글 5편, 블로그에 실린 공식 사이트 화면 이미지를 바탕으로 썼습니다.

- 요금: 블로그 글의 국내 공식 요금 안내(2026년 11월 3일 공개 기준, 부가세 별도). Advanced 상담원 3명(3유저 1팩) 연 30만원, 상담원 1명 연 15만원, 상시 접속 장치 100대 팩 연 30만원, 구성 예시(상담원 1명 + 장치 100대 = 연 45만원). 상담원당 동시 지원 세션 무제한.
- 체험: 공식 사이트 이미지의 '14일 무료 사용 신청', '최대 1개월 체험판(모든 기능 제한 없이 사용)'.
- 기능: 공식 사이트 이미지의 핵심 기능, 원격 제어 패널, 상시 원격 접속, 빠른 지원(초대 다섯 가지 방법), 설치형 대시보드, 공유 액세스, Wake-on-LAN, 보안 5가지, 플러그인과 통합, 브랜딩, 여러 상담원 동시 참여, 사용자·권한 관리.
- 운영체제: 공식 '크로스 플랫폼' 목록(Windows 7 이상, Windows Server 2008 R2 이상, macOS 10.12 이상, 리눅스 모든 버전, 안드로이드 7.0 이상). 이 목록에 iOS는 없어서, iOS는 소개글의 'iOS 지원'만 적고 기능 범위는 '채울 자리'로 두었습니다.
- 접속 주소(블로그의 363 안내 이미지): 무료로 시작하기·FREE·체험판 → https://go.363.co.kr, 원격지원 받기(고객용) → https://363.co.kr, 상담원 로그인 → https://1.363.co.kr. 공식 사이트는 https://getscreen.kr.
- 상호는 아이비인포텍입니다.

검증할 수 없는 문구('국내 최초', '가성비 끝판왕')와 블로그 글 속 경쟁 제품 비교 수치는 쓰지 않았습니다.

자료가 없는 대표자, 주소, 사업자등록번호, 운영 시간, 다른 요금제와 요금제별 기능 비교표, FREE 버전 제공 범위, iOS 기능 범위, 내려받기 링크와 사용 설명서는 '채울 자리'로 표시해 두었습니다. 개인정보 수집 동의 문구는 예시입니다.

## 페이지

| 주소 | 내용 |
| --- | --- |
| `/` | 메인: 원격지원 애니메이션, 고객용 접속 바로가기, 제품 화면이 들어간 핵심 기능 6개, 연결 3단계, 요금 요약, 활용 분야, 최근 블로그 글 5편(표지) |
| `features/` | 기능: 빠른 지원, 원격 제어 패널, 여러 상담원 동시 참여, 상시 접속, 설치형 대시보드, 공유 액세스, Wake-on-LAN, 지원 운영체제, 계정과 권한, 보안, 플러그인과 통합, 브랜딩 (위쪽 바로가기 줄 포함) |
| `pricing/` | 요금: FREE·체험판, Advanced(연 30만원), 상시 접속 장치(100대 연 30만원), 구성 예시, 요금 질문 |
| `guide/` | 사용 방법: 빠른 지원 3단계와 초대 방법, 무인 접속 3단계, 접속 주소 3곳, 내려받기(채울 자리) |
| `support/` | 고객지원: 원격지원 받기·전화·카카오톡·이메일, 자주 묻는 질문 11개, 블로그 글 24개를 분류별로 걸러 보기 |
| `contact/` | 도입 문의 폼 (입력 확인만 하고 실제 전송은 없음) |
| `404.html` | 없는 주소 안내 |

`contact/?plan=advanced`, `contact/?plan=device`로 들어오면 문의 내용에 해당 요금제가 미리 적히고 문의 유형이 '견적 문의'로 선택됩니다. `contact/?type=tech`처럼 유형만 고를 수도 있습니다(`intro`, `quote`, `tech`, `etc`).

첫 화면의 원격지원 그림은 HTML·CSS로 만든 애니메이션으로, 10초 주기로 연결 → 오류 창 → 설정 변경 → 해결을 반복합니다. 화면 밖으로 나가면 멈추고, 기기에서 '동작 줄이기'를 켜면 해결된 장면으로 고정됩니다.

블로그 글은 받은 5편(2026.10.07~11.04)만 표지를 넣고 해당 글로 연결합니다. 나머지 19편은 글별 주소를 받기 전이라 블로그 첫 화면으로 연결합니다.

## 그림 (`assets/img`)

모두 공식 블로그 이미지에서 잘라 낸 임시 자료입니다. 원본 파일을 받으면 바꿔 주세요. 그림을 바꾸면 `src/images.mjs`의 크기도 같이 고칩니다.

- `logo.png`, `logo-white.png`: 블로그의 363 안내 이미지에서 잘라 바탕을 투명하게 만든 Getscreen.me 로고입니다. 원본 로고 파일로 바꿔야 합니다. `assets/favicon.png`, `img/touch-icon.png`도 같은 로고의 아이콘 부분입니다.
- `ui-*.webp`: 공식 사이트 화면 이미지에서 제목·본문·버튼을 빼고 제품 화면만 잘라 냈습니다. 해상도가 낮아서 원본 크기보다 크게 보이지 않게 했습니다.
  - `ui-invite`: 고객 초대
  - `ui-join`: 고객이 받는 초대 메일
  - `ui-customer`: 고객 화면
  - `ui-agents`: 여러 상담원 참여
  - `ui-multi`: 무제한 동시 연결
  - `ui-device-card`: 설치형 대시보드
  - `ui-access`: 공유 액세스
  - `ui-wol`: Wake-on-LAN
  - `ui-device-add`: 크로스 플랫폼
  - `ui-team`: 사용자·권한 관리
  - `ui-chrome`: Chrome 확장
  - `ui-brand`: 브랜딩
  - `ui-toolbar`: 원격 제어 도구 모음
- `cover-<글 번호>-160.webp`, `-400.webp`: 블로그 글 5편의 표지
- 그림 전체 약 240KB (공유 이미지 `og.png` 69KB 별도)

경쟁 제품 화면과 스톡 사진은 쓰지 않았습니다.

## 구조

- `src/content.mjs`: 모든 문구 (요금, 기능, 자주 묻는 질문, 블로그 글 목록 포함)
- `src/images.mjs`: 그림 크기와 바탕색
- `src/art.mjs`: 아이콘, 첫 화면의 원격지원 애니메이션
- `src/layout.mjs`: 바로가기 줄, 헤더, 모바일 메뉴, 푸터, 상담 버튼
- `src/pages.mjs`: 페이지별 본문
- `build.mjs`: 위 내용으로 HTML을 만듭니다
- `assets/css/site.css`, `assets/js/site.js`: 디자인과 화면 동작
- `assets/fonts`: Pretendard (SIL OFL, 라이선스 파일 포함)
- `assets/og.png`: 링크 공유 이미지 (1200×630)

## 고치는 방법

1. `src/content.mjs`의 문구를 고칩니다.
2. 이 폴더에서 `node build.mjs`를 실행합니다 (Node 18 이상, 설치할 패키지 없음).
3. 만들어진 HTML과 함께 커밋해서 `main`에 올리면 GitHub Pages에 반영됩니다.

시안이라 검색엔진 수집은 막아 두었습니다(`noindex`).
