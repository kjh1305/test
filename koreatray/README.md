# 글로벌 코리아트레이 홈페이지 시안

(주)코리아트레이 홈페이지 시안입니다. 주소는 https://kjh1305.github.io/test/koreatray/ 입니다.

회사 정보는 회사가 준 자료와 블로그(데이 드리머, (주)코리아 트레이)를 바탕으로 썼습니다. 자료가 없는 연혁, 인증·시험성적서, 규격표, 공장 사진, 대표 인사말은 '채울 자리'로 표시해 두었습니다.

## 언어

한국어, 영어, 일본어, 베트남어, 태국어로 볼 수 있습니다. 오른쪽 위 언어 버튼을 누르면 보고 있던 페이지의 다른 언어판으로 바로 이동합니다.

| 언어 | 주소 |
| --- | --- |
| 한국어 | `/koreatray/` |
| English | `/koreatray/en/` |
| 日本語 | `/koreatray/ja/` |
| Tiếng Việt | `/koreatray/vi/` |
| ไทย | `/koreatray/th/` |

브라우저 언어가 페이지 언어와 다르면 화면 아래에 해당 언어로 보기 안내가 한 번 뜹니다. 언어를 직접 고르거나 안내를 닫으면 다시 뜨지 않습니다.

## 페이지

| 주소 | 내용 |
| --- | --- |
| `/` | 메인: 접히는 트레이 첫 화면, 거래 브랜드, 선언 문구, 제품 분류, 한 달 120만 개, 생산 과정, 강점, 상담에 필요한 네 가지, 블로그 최근 글, 해외 문의 |
| `about/` | 회사소개: 대표 인사말(예시 문안), 회사 개요, 강점, 연혁과 인증(채울 자리), 공장과 서울사무소 지도 |
| `products/` | 제품소개: 5개 분류, 4면 접착과 8면 접착 비교, 두께 고르는 기준 |
| `quality/` | 생산·품질: 칼선 설계부터 납품까지 7단계(스크롤에 맞춰 그림이 바뀜), 품질 기준, 공장 사진 자리 |
| `contact/` | 문의: 견적·샘플 문의 폼(입력 확인만 하고 실제 전송은 없음), 연락처 |

`contact/?product=chicken`처럼 제품을 붙이면 문의 폼에서 그 제품이 미리 선택됩니다(`chicken`, `bakery`, `street`, `takeout`, `custom`). `?type=sample`이면 샘플 요청이 선택됩니다.

## 구조

- `src/content.mjs`: 모든 문구 (언어별로 `L(한국어, 영어, 일본어, 베트남어, 태국어)` 순서)
- `src/art.mjs`: 제품 일러스트, 칼선 도면, 아이콘 (SVG)
- `src/layout.mjs`: 헤더, 언어 선택, 모바일 메뉴, 푸터, 첫 화면의 접히는 트레이
- `src/pages.mjs`: 페이지별 본문
- `build.mjs`: 위 내용으로 언어별 HTML을 만듭니다
- `assets/css/site.css`, `assets/js/site.js`: 디자인과 화면 동작
- `assets/fonts`: Pretendard, Pretendard JP, Noto Sans Thai (모두 SIL OFL, 라이선스 파일 포함)

## 고치는 방법

1. `src/content.mjs`의 문구를 고칩니다.
2. 이 폴더에서 `node build.mjs`를 실행합니다 (Node 18 이상, 설치할 패키지 없음).
3. 만들어진 HTML과 함께 커밋해서 `main`에 올리면 GitHub Pages에 반영됩니다.

실제 사진이 생기면 `src/art.mjs`의 일러스트 대신 사진을 넣으면 됩니다. 실제 운영할 때는 문의 폼을 메일 발송 서비스와 연결해야 합니다.

시안이라 검색엔진 수집은 막아 두었습니다(`noindex`).
