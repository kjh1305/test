- 헤더 오른쪽 해/달 버튼(모바일은 메뉴 안 버튼)으로 어두운 화면 ↔ 밝은 화면. 기본은 어두운 화면이고, 고른 쪽을 브라우저에 기억함(`localStorage` 'ik-theme')
