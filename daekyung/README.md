블로그 글의 '시공 비용 30% 이상 절감' 같은 수치는 쓰지 않았습니다. 공종 설명, 원상복구 전에 확인할 것, 진행 과정(현장 확인 → 견적 → 시공 → 마감·정리)은 일반적인 설명이라 업체에 확인해야 합니다. 대표자, 주소, 사업자등록번호, 면허, 이메일, 상담 시간은 아직 몰라서 '자료를 받으면 채울 자리'로 표시해 두었습니다.

업체가 "엄청 간단하고 심플하고 깔끔한 디자인"을 원해서 흰 바탕에 파란 계열 한 가지(남색 `#142B5C`, 도면 청색 `#1E4DB7`, 회청색 `#4A5F7E`)만 쓰고, 여백을 넉넉히 두고, 움직임은 스크롤할 때 살짝 나타나는 것만 넣었습니다. 로고는 따로 만들지 않고 상호를 글자로만 썼습니다. 파비콘도 '대' 글자 하나입니다.

메인은 업체가 고른 참고 사이트 두 곳(하은M&A, 성은건설정보)의 짜임새를 따랐습니다: 알림 팝업, 사진 위 가운데 정렬 첫 화면(큰 전화번호와 바로가기 버튼), 공종 아이콘 줄, 회사 소개 블록, 화면 끝까지 닿는 큰 사업분야 블록, 떠 있는 상담 버튼. 참고 사이트의 글, 로고, 그림은 쓰지 않았습니다. 하위 페이지는 내용은 그대로 두고 머리 부분만 남색 띠로 맞췄습니다.

## 채울 자리

`src/content.mjs`에서 `null`로 둔 값은 화면에 '자료를 받으면 채울 자리'로 나옵니다. 값을 넣으면 그 자리에 그대로 들어갑니다.

| 항목 | 위치 (`src/content.mjs`) | 나오는 곳 |
| --- | --- | --- |
| 대표자 | `CO.ceo` | 회사 정보, 푸터 |
| 주소 | `CO.address` | 회사 정보, 푸터 |
| 사업자등록번호 | `CO.bizNo` | 회사 정보, 푸터 |
| 면허·등록 | `CO.license` | 회사 정보 |
| 이메일 | `CO.email` | 회사 정보, 견적문의 |
| 상담 시간 | `CO.hours` | 견적문의 |

전화번호(`CO.phone`)는 블로그의 010-5478-4364를 넣었습니다. 메인 첫 화면, 헤더, 떠 있는 '상담' 버튼, 모바일 메뉴, 모바일 하단 바, 문의 띠, 견적문의, 회사 정보, 푸터에 나오고, 누르면 전화가 걸립니다. 값을 `null`로 바꾸면 채울 자리로 돌아가고, 첫 화면 전화번호와 '상담' 버튼은 빠집니다. 알림 팝업의 전화(`POPUPS`의 `tel`)는 따로 고쳐야 합니다.

글로 채우는 것이 아닌 자리도 있습니다. 대표 인사말과 대표 사진, 오시는 길 지도는 `src/pages.mjs`의 `about()`에 점선 상자로 들어 있으니, 자료를 받으면 그 부분을 바꿉니다. 견적문의의 개인정보 안내(`CONTACT.privacyText`)는 예시 문구라 회사 기준으로 바꿔야 합니다.

## 알림 팝업 (메인)

메인에 들어오면 첫 화면 위에 업체 홍보 배너가 레이어 팝업으로 뜹니다. 넓은 화면에서는 첫 화면 왼쪽 위에, 모바일(640px 이하)에서는 화면 가운데에 화면 너비의 90%로 뜨고 뒤가 어두워집니다.

- 내용은 `src/content.mjs`의 `POPUPS`에서 정합니다. 여러 개를 넣을 수 있고, `on: false`로 두면 나오지 않습니다.
- `id`는 '오늘 하루 열지 않기' 기록에 쓰므로 팝업마다 달라야 합니다. 그림을 바꾸면 `id`도 바꿔야 이미 닫은 사람에게도 다시 뜹니다.
- '오늘 하루 열지 않기'를 고르고 닫으면 오늘 자정까지 열리지 않습니다(브라우저 `localStorage`, 저장이 막힌 브라우저에서는 매번 열림).
- 닫기: '닫기' 버튼, Esc 키, 모바일에서는 어두운 바깥을 누름. 열리면 '닫기'에 초점이 갑니다.
- 그림을 누르면 모바일에서는 전화(`tel`)가 걸리고, 넓은 화면에서는 견적문의(`href`)로 갑니다.
- 팝업은 JS가 열어 줍니다. JS가 꺼져 있으면 보이지 않습니다.
- 그림(`popup-banner.webp`)은 업체 블로그의 홍보 배너입니다. 오른쪽 아래의 생성 도구 표시(Genspark)는 같은 파란 띠로 덮었습니다. 업체가 원본 배너 파일을 주면 바꾸는 것이 좋습니다.

## 떠 있는 버튼

넓은 화면에서는 오른쪽 아래에 '상담'(누르면 전화)과 TOP(조금 내리면 나타남) 버튼이 떠 있습니다. 모바일에서는 화면 아래 전화·견적문의 바가 그대로 있고, TOP만 그 위에 뜹니다. 카카오톡 채널이 없어 카카오톡 버튼은 넣지 않았습니다.

## 사진 넣는 방법

사진 자리는 모두 `src/content.mjs`의 데이터로 정해집니다. `img`가 `null`이면 점선 상자가 나오고, 파일 이름을 넣으면 사진이 나옵니다.

| 자리 | 데이터 | 비율 |
| --- | --- | --- |
| 메인 첫 화면 배경 | `HERO_IMG` | 화면 크기에 맞춰 잘림 (가로 1600px 이상이면 흐림을 빼도 됨: `.hero-bg img`) |
| 메인 회사 소개 블록 | `HOME.aboutImg` | 4:3 |
| 알림 팝업 | `POPUPS`의 각 항목 | 그림 비율 그대로 |
| 사업분야 사진 10개 | `SERVICES`의 각 항목 | 4:3 |
| 시공사례 | `PROJECTS`의 각 항목 (`cover`, `gallery`) | 4:3 |

1. 사진을 WebP로 줄여 `assets/img/`에 넣습니다 (가로 800~1600px).
2. 그 자리의 데이터에 파일 이름과 크기, 설명을 넣습니다.
   ```js
   { id: 'floor', name: '바닥공사', …, img: 'svc-floor.webp', w: 800, h: 600, alt: '상가 바닥 마감을 마친 모습' }
   ```
3. 사진은 정해진 비율에 맞춰 잘려 보입니다(`object-fit: cover`). `w`, `h`는 사진의 실제 크기를 적습니다(화면이 밀리지 않게 하는 용도).
4. 시공사례를 늘리려면 `PROJECTS`에 항목을 하나 더 넣습니다. `id`, `title`, `where`, `url`(블로그 글), `summary`, `works`(공사 내용), `services`(공사 종류 id), `cover`, `gallery`를 채우면 시공사례 페이지와 사업분야의 '관련 사례'에 나옵니다. 메인에는 앞의 3개가 나옵니다.

## 구조

- `src/content.mjs`: 모든 문구, 회사 정보, 알림 팝업(`POPUPS`), 아이콘 줄(`QUICK`), 큰 블록(`BLOCKS`), 사업분야, 시공사례, 자주 묻는 질문, 사진 자리
- `src/art.mjs`: 아이콘, 공종 선 아이콘(메인 아이콘 줄과 큰 블록 바탕 그림)
- `src/layout.mjs`: `<head>`, 헤더, 모바일 메뉴, 푸터, 모바일 하단 전화·문의 바, 떠 있는 상담·TOP 버튼, 사진 자리와 채울 자리 표시
- `src/pages.mjs`: 페이지별 본문
- `build.mjs`: 위 내용으로 HTML을 만듭니다
- `assets/css/site.css`, `assets/js/site.js`: 디자인과 화면 동작(모바일 메뉴, 알림 팝업, 맨 위로, 나타나는 효과, 사진 크게 보기, 폼 확인)
- `assets/img`: 현장 사진 (WebP)
- `assets/og.png`, `assets/favicon.png`, `assets/apple-touch-icon.png`: 공유 이미지(1200×630)와 아이콘
- `assets/fonts`: Pretendard (SIL OFL, 라이선스 파일 포함)

## 고치는 방법

1. `src/content.mjs`의 문구와 값을 고칩니다. 사진은 `assets/img/`에 넣습니다.
2. 이 폴더에서 `node build.mjs`를 실행합니다 (Node 18 이상, 설치할 패키지 없음).
3. 만들어진 HTML과 함께 커밋해서 `main`에 올리면 GitHub Pages에 반영됩니다.

시안이라 검색엔진 수집은 막아 두었습니다(`noindex`).
