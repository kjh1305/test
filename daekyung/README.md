# 대경기업 홈페이지 시안

대경기업 홈페이지 시안입니다. 주소는 https://kjh1305.github.io/test/daekyung/ 입니다. 2차 시안은 업체가 보낸 의뢰서(회사소개 글, 메뉴, 원하는 분위기, 참고 사이트 3곳)를 기준으로 다시 만들었습니다.

## 바탕 자료

- **업체 의뢰서 (2026-11, 2차 시안의 기준)**
  - 회사소개 글 (회사소개 페이지에 그대로 실음. 의뢰서에는 상호가 '대경 다이벌스'로 적혀 있어, 확인 전까지 블로그 상호 '대경기업'으로 둠)
  - 메뉴: 회사소개 / 칸막이 천정공사 / 원상복구 / 인테리어 / 공장보수공사 / 수장공사 / 견적문의
  - 디자인: 깔끔하고 고급스러우면서 단순하고 눈에 띄게, 견적문의는 계속 보이게. 로고는 이미지로 줄 예정
  - 목적: 홍보 및 예약접수
  - 참고 사이트: 한샘 인테리어 전용관(store.hanssem.com/plan/19924), 도트스페셜(dotspecial.co.kr), 비에프아트(bfart.co.kr)
- 블로그(m.blog.naver.com/tk51123) 글 3개와 사진: 전화번호, 시공 지역(서울·경기 수도권), 시공사례, 자주 묻는 질문

## 디자인 (2차)

참고 사이트 세 곳을 열어 본 공통점: 흰 바탕과 먹색, 따뜻한 회색 면, 색은 거의 쓰지 않고 사진을 크게 씀, 번호 붙은 진행 과정, 사진 격자 시공사례, 문의 폼. 한샘은 오른쪽 아래에 '무료 견적 상담' 원형 버튼이 늘 떠 있음.

- 색: 흰색, 먹색 `#151515`, 석재 회색 `#F3F1EC`. 색은 견적문의에만 코발트 청색 `#1F4FD8` 하나 (흰 글자 대비 6.1:1). 업체 블로그 배너의 파란색과 같은 계열. 로고 색을 받으면 이 색만 바꾸면 됨 (`--point`)
- 글꼴: Pretendard, 제목 700 굵기에 자간을 좁혀 단단하게
- 모서리 2px, 그림자는 떠 있는 버튼에만
- 견적문의가 계속 보이게: 헤더의 견적문의 버튼(고정 헤더), 오른쪽 아래 떠 있는 원형 '견적문의' 버튼(PC), 화면 아래 전화·견적문의 바(모바일), 페이지 끝 코발트 문의 띠
- 알림 팝업: 블로그 홍보 배너를 메인에 띄움. PC는 첫 화면 오른쪽 위(사진 위), 모바일은 화면 가운데. '오늘 하루 열지 않기' 있음. 끄려면 `POPUPS`의 `on: false`
- 오른쪽 아래 떠 있는 버튼: 블로그(새 창) · 견적문의 · 맨 위로. 모바일은 블로그 · 맨 위로만 뜨고 견적문의는 하단 바가 맡음

## 채울 자리

`src/content.mjs`에서 `null`로 둔 값은 화면에 '자료를 받으면 채울 자리'로 나옵니다. 값을 넣으면 그 자리에 그대로 들어갑니다.

| 항목 | 위치 (`src/content.mjs`) | 나오는 곳 |
| --- | --- | --- |
| 대표자 | `CO.ceo` | 회사 정보, 푸터 |
| 주소 | `CO.address` | 회사 정보, 푸터 |
| 사업자등록번호 | `CO.bizNo` | 회사 정보, 푸터 |
| 면허·등록 | `CO.license` | 회사 정보 |
| 이메일 | `CO.email` | 회사 정보, 견적문의 |
| 상담 시간 | `CO.hours` | 견적문의 |

전화번호(`CO.phone`)는 블로그의 010-0000-0000를 넣었습니다. 메인 첫 화면, 헤더, 떠 있는 '상담' 버튼, 모바일 메뉴, 모바일 하단 바, 문의 띠, 견적문의, 회사 정보, 푸터에 나오고, 누르면 전화가 걸립니다. 값을 `null`로 바꾸면 채울 자리로 돌아가고, 첫 화면 전화번호와 '상담' 버튼은 빠집니다. 알림 팝업의 전화(`POPUPS`의 `tel`)는 따로 고쳐야 합니다.

글로 채우는 것이 아닌 자리도 있습니다. 오시는 길 지도는 `src/pages.mjs`의 `about()`에 점선 상자로 들어 있으니, 자료를 받으면 그 부분을 바꿉니다. 견적문의의 개인정보 안내(`CONTACT.privacyText`)는 예시 문구라 회사 기준으로 바꿔야 합니다.

## 사진 넣는 방법

사진 자리는 모두 `src/content.mjs`의 데이터로 정해집니다. `img`가 `null`이면 점선 상자가 나오고, 파일 이름을 넣으면 사진이 나옵니다.

| 자리 | 데이터 | 비율 |
| --- | --- | --- |
| 메인 첫 화면 사진 2장 | `HOME.heroImgs` | 4:5, 1:1 |
| 알림 팝업 | `POPUPS`의 각 항목 | 그림 비율 그대로 |
| 사업분야 사진 10개 | `SERVICES`의 각 항목 | 4:3 |
| 시공사례 | `PROJECTS`의 각 항목 (`cover`, `gallery`) | 4:3 |

1. 사진을 WebP로 줄여 `assets/img/`에 넣습니다 (가로 800~1600px).
2. 그 자리의 데이터에 파일 이름과 크기, 설명을 넣습니다.
   ```js
   { id: 'floor', name: '바닥공사', …, img: 'svc-floor.webp', w: 800, h: 600, alt: '상가 바닥 마감을 마친 모습' }
   ```
3. 사진은 정해진 비율에 맞춰 잘려 보입니다(`object-fit: cover`). `w`, `h`는 사진의 실제 크기를 적습니다(화면이 밀리지 않게 하는 용도).
4. 시공사례를 늘리려면 `PROJECTS`에 항목을 하나 더 넣습니다. `id`, `title`, `where`, `url`(블로그 글), `summary`, `works`(공사 내용), `services`(공사 종류 id), `cover`, `gallery`를 채우면 시공사례 페이지와 사업분야의 '관련 사례'에 나옵니다. 메인에는 앞의 3개가 나옵니다.

## 구조

- `src/content.mjs`: 모든 문구, 회사 정보, 알림 팝업(`POPUPS`), 사업분야(`SERVICES`), 일하는 원칙(`PRINCIPLES`), 시공사례, 자주 묻는 질문, 사진 자리
- `src/art.mjs`: 아이콘
- `src/layout.mjs`: `<head>`, 헤더, 모바일 메뉴, 푸터, 모바일 하단 전화·문의 바, 떠 있는 상담·TOP 버튼, 사진 자리와 채울 자리 표시
- `src/pages.mjs`: 페이지별 본문
- `build.mjs`: 위 내용으로 HTML을 만듭니다
- `assets/css/site.css`, `assets/js/site.js`: 디자인과 화면 동작(모바일 메뉴, 알림 팝업, 맨 위로, 나타나는 효과, 사진 크게 보기, 폼 확인)
- `assets/img`: 현장 사진 (WebP)
- `assets/og.png`, `assets/favicon.png`, `assets/apple-touch-icon.png`: 공유 이미지(1200×630)와 아이콘
- `assets/fonts`: Pretendard (SIL OFL, 라이선스 파일 포함)

## 고치는 방법

1. `src/content.mjs`의 문구와 값을 고칩니다. 사진은 `assets/img/`에 넣습니다.
2. 이 폴더에서 `node build.mjs`를 실행합니다 (Node 18 이상, 설치할 패키지 없음).
3. 만들어진 HTML과 함께 커밋해서 `main`에 올리면 GitHub Pages에 반영됩니다.

시안이라 검색엔진 수집은 막아 두었습니다(`noindex`).
