# LS셔터 홈페이지 시안

LS셔터(주식회사 성현 직영) 홈페이지 시안입니다. 주소는 https://kjh1305.github.io/test/lsshutter/ 입니다.

의뢰받은 작업이 아니라 포트폴리오용 예시로 만든 시안입니다. 푸터에도 "이 사이트는 홈페이지 제작 시안입니다…"라는 안내를 넣었습니다.

### 인정 상태 표기 (중요)

인정 상태는 원문 표현을 한 글자도 바꾸지 않고 씁니다. 법적으로 의미가 다르므로 한 단계 올려 쓰면 안 됩니다.

| 상태 | 제품 |
| --- | --- |
| 인정서 보유 | 철재 방화셔터 SH-F01, 스크린 방화셔터 SH-S01 |
| 시험 통과 · 인정서 발급 대기 | 철재 방화셔터 90분 SH-F02, 초대형 스크린 SH-TS01 · TS02 |
| 시험 전 · 판매 불가 | 복합방화철재 SH-CF01, 복합방화스크린 SH-CS01 (인정 완료 전까지 판매·유통하지 않음, 견적문의 선택지에서 뺌) |

인정 진행 중 현황은 원문 기준 2026년 10월입니다. 상태 문구는 `src/content.mjs`의 `STATUS` 한 곳에 있고, 제품에는 `status: 'cert' | 'pending' | 'notsale'` 키만 붙입니다. 상태가 바뀌면 키만 바꾸고, 인정서가 나오면 `specs`의 인정번호와 `CERTS`(품질인정 표)를 함께 고칩니다. 방화셔터가 아닌 제품(A/L, 방범, 자재, 기타)은 상태 대신 회색 `tag`(단열 · 내풍압, 현장 맞춤 제작 …)만 붙입니다.

## 디자인

"지금 사이트(seonghyun.co.kr)를 바탕으로, 두 번째 샘플(ydshutter.com)처럼 더 깔끔하게"라는 요청에 맞췄습니다. ydshutter의 짜임새와 여백만 참고했고, 그 사이트의 글·로고·그림은 쓰지 않았습니다. 내용은 성현 사이트의 실제 정보를 줄이고 정리했습니다.

- 색: 흰 바탕과 따뜻한 회색(모래색), 강조는 방화를 떠올리는 호박색 한 가지, 푸터는 짙은 남색. 흰 글자를 얹는 버튼은 글자 대비를 맞추려고 조금 진한 호박색(`--amber-btn`)을 씁니다.
- 글꼴: Pretendard 하나
- 로고: 글자만 ("LS셔터" + "주식회사 성현 직영"). 따로 만든 엠블럼은 없습니다. 파비콘도 'LS' 글자입니다.
- 헤더: 흰 바탕, 왼쪽 로고, 가운데 메뉴 5개, 오른쪽 둥근 호박색 전화 아이콘 + 굵은 대표번호
- 첫 화면: 화면 너비 슬라이드 3장, 왼쪽 정렬 문구, 아래 왼쪽에 "01 / 03"과 ‹ ❚❚ › 버튼
- 사진이 아직 없어 첫 화면, 문의 띠, 두 패널, 하위 페이지 머리, 404의 바탕은 SVG로 그린 셔터 그림입니다(철재 슬랫, 실리카 직물 스크린, 반쯤 내린 셔터). 사진을 받으면 데이터만 바꾸면 됩니다.
- 넓은 화면 오른쪽 아래에 둥근 호박색 TOP 버튼, 모바일은 화면 아래 고정 상담 바(전화 · 문자·사진 · 견적문의)

## 사진 넣는 법

사진은 아직 없습니다(업체 블로그 사진을 받으면 넣을 예정). 사진 자리는 모두 `src/content.mjs`의 데이터로 정합니다.

- `img: null` → 점선 줄무늬 상자 '사진 자리 · 자료를 받으면 채울 자리' (제품 자리에는 제품 선 그림을 흐리게 함께 그림)
- `img: 'x.webp', w: 1200, h: 900, alt: '사진 설명'` → `assets/img/x.webp`

1. 사진을 WebP로 줄여 `assets/img/`에 넣습니다 (가로 1000~1600px, 첫 화면은 1920px 이상이 좋음).
2. 그 자리의 `img`에 파일 이름, `w`와 `h`에 실제 픽셀 크기, `alt`에 한국어 설명을 적습니다.
3. 다시 빌드합니다. 사진은 자리의 비율(대부분 4:3)에 맞춰 잘려 보입니다.

| 자리 | 데이터 |
| --- | --- |
| 첫 화면 슬라이드 3장 | `HERO.slides` (`img`를 넣으면 그 장은 그림 대신 사진) |
| 홈 COMPANY, 회사소개 첫 블록 | `COMPANY.img` |
| 제품 8개 (홈 카드와 제품 페이지) | `PRODUCTS[].img` |
| 공장 사진 3장 | `FACTORY_PHOTOS` |
| 납품 현장 4곳 | `RECORDS[].img` |
| 인정서 사본 2장 | `CERT_META.scans` (A4 세로 비율) |

예) 철재 방화셔터: `PRODUCTS`의 `f01` 항목에 `img: 'prod-f01.webp', w: 1200, h: 900, alt: '주차장 출입구에 설치한 철재 방화셔터'`

문의 띠와 두 패널의 바탕은 지금 그림입니다. 사진으로 바꾸려면 `pages.mjs`의 `backdrop(c, null, …)`에서 `null` 자리에 `{ img, w, h }`를 넣습니다.

## 알림 팝업 (지금은 꺼짐)

중앙설비산업 · 대경기업 시안과 같은 레이어 팝업입니다. 지금은 꺼져 있어 HTML에 들어가지 않습니다. `src/content.mjs`의 `POPUPS`에서 관리합니다.

```js
export const POPUPS = [
  { id: 'notice-2026-11', on: false, img: null, w: 0, h: 0, alt: '', label: 'LS셔터 안내',
    title: 'LS셔터 안내', text: '현장 규격과 사진만 보내 주시면 바로 견적을 드립니다.', href: 'contact/', tel: 'tel:0317649573' }
];
```

- 켜기: `on: true`로 바꾸고 다시 빌드합니다. 모두 `false`면 팝업이 아예 나오지 않습니다.
- 그림 팝업: 그림을 WebP로 `assets/img`에 넣고 `img`, `w`, `h`, `alt`(그림 속 글자를 그대로)를 적습니다. `img`가 `null`이면 `title`, `text`와 대표번호로 만든 글 팝업이 나옵니다.
- 내용을 바꾸면 `id`도 바꿔야 '오늘 하루 열지 않기'를 누른 사람에게도 새 팝업이 보입니다.
- 여러 개를 넣으면 넓은 화면에서는 나란히, 모바일에서는 위아래로 쌓입니다.
- 누르면 `href`로 갑니다. 모바일에서는 `tel`이 있으면 전화를 겁니다.
- '오늘 하루 열지 않기'를 고르고 닫으면 그 브라우저에 오늘 자정까지 기록됩니다(`localStorage`의 `lsshutter-pop-` + id). 저장이 막힌 브라우저에서는 매번 열립니다.
- 넓은 화면에서는 첫 화면 위 왼쪽에 뜨고 뒤를 가리지 않습니다. 모바일(760px 이하)에서는 가운데에 뜨고 뒤를 어둡게 합니다. Esc나 '닫기'로 닫힙니다. 자바스크립트가 꺼져 있으면 나오지 않습니다.

## 화면 동작

- 첫 화면은 6초마다 넘어갑니다. 마우스를 올리거나 키보드로 들어오면 잠시 멈추고, ❚❚ 버튼으로 끌 수 있습니다. 조작 버튼에 초점이 있을 때 ←, → 키로도 넘깁니다.
- '동작 줄이기'를 켠 기기에서는 자동으로 넘기지 않고(재생 버튼 상태로 시작), 확대·나타남 효과도 없습니다.
- 견적문의 폼은 담당자, 연락처, 문의 내용, 개인정보 동의를 확인하고 실제로 보내지는 않습니다(시안 안내 알림만 뜸).

## 구조

- `src/content.mjs`: 모든 문구, 회사 정보, 제품 · 인정 · 실적 데이터, 사진 자리, 알림 팝업
- `src/art.mjs`: 아이콘, 제품 선 그림, 셔터 바탕 그림(SVG), 물결 선
- `src/layout.mjs`: `<head>`, 헤더, 모바일 메뉴, 푸터, 모바일 하단 상담 바, TOP 버튼, 사진 자리, 상태 배지, 하위 페이지 머리 (`ctx(slug)`로 상대 주소를 만들어 하위 폴더에서도 동작)
- `src/pages.mjs`: 페이지별 본문
- `build.mjs`: 위 내용으로 HTML을 만듭니다
- `assets/css/site.css`, `assets/js/site.js`: 디자인과 화면 동작
- `assets/img/`: 사진 넣을 곳 (지금은 비어 있음)
- `assets/og.png`(공유 이미지 1200×630), `assets/favicon.png`, `assets/apple-touch-icon.png`
- `assets/fonts`: Pretendard (SIL OFL, 라이선스 파일 포함)

## 고치는 방법

1. `src/content.mjs`의 문구나 값을 고칩니다. 사진은 `assets/img/`에 넣습니다.
2. 이 폴더에서 `node build.mjs`를 실행합니다 (Node 18 이상, 설치할 패키지 없음).
3. 만들어진 HTML과 함께 커밋해서 `main`에 올리면 GitHub Pages에 반영됩니다.

시안이라 검색엔진 수집은 막아 두었습니다(`noindex`).
