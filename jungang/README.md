# 중앙설비산업 홈페이지 시안

중앙설비산업 홈페이지 시안입니다. 주소는 https://kjh1305.github.io/test/jungang/ 입니다.

중앙설비산업은 울산을 중심으로 영남 지역(울산, 부산, 경남, 경북, 김해, 경주, 양산, 창원, 포항) 공장과 산업단지의 산업용 보일러를 세관하고 수리하며, 법정검사를 대행하는 업체입니다. 그래서 공장 동력·설비 담당자가 읽는 사이트로 만들었습니다.

내용은 업체가 준 연락처 글과 블로그 글 2개, 홍보 배너의 사업 목록(배너 이미지는 쓰지 않고 문구만), 블로그 해시태그를 바탕으로 썼습니다. 대표자, 정확한 주소, 사업자등록번호, 면허·등록 사항, 실적 수는 '채울 자리'로 표시해 두었습니다. 회사소개의 인사말은 예시 문안입니다. 사업분야 설명은 일반적인 내용이라 업체 확인이 필요합니다.

- 대표 전화(휴대폰) 010-0000-0000, 사무실 052-260-0277, 이메일 example@example.com
- 기존 홈페이지 이름 '보일러세관.com'은 링크 없이 글자로만 넣었습니다.
- 블로그: https://blog.naver.com/boiler21

## 디자인

업체가 고른 참고 사이트처럼 남색·파랑 바탕의 제조·설비 업체 사이트 형식입니다. 주황은 전화 버튼에만 씁니다. 글꼴은 Pretendard 하나입니다.

- 헤더: 왼쪽 업체 이름, 가운데 메뉴(회사소개, 사업분야, 작업사례, 상담문의, 블로그), 오른쪽 전화 버튼과 남색 '견적문의' 버튼
- 넓은 화면 오른쪽에 고정 퀵메뉴(상담문의, 전화, 블로그, TOP), 모바일은 아래에 고정 상담 바(전화, 견적문의)
- 서브 페이지 첫 화면은 어두운 현장 사진 띠 + 제목 + 현재 위치
- 푸터는 짙은 회색에 가운데 정렬 정보 줄, 개인정보처리방침 | 이용약관 링크

## 채울 자리

점선 줄무늬 상자에 '자료를 받으면 채울 자리'라고 표시된 곳입니다. 모두 `src/content.mjs`에서 값을 넣으면 사라집니다.

| 항목 | 고칠 곳 | 나오는 곳 |
| --- | --- | --- |
| 대표자 | `CO.rep` | 회사소개 인사말 서명, 업체 정보, 푸터 |
| 정확한 주소 | `CO.address` | 업체 정보, 푸터 (지도는 `pages.mjs`의 `map-ph`를 지도로 바꿈) |
| 사업자등록번호 | `CO.bizNo` | 업체 정보, 푸터 |
| 면허·등록 | `CO.license` | 업체 정보 |
| 사업분야 사진 3곳 | `SERVICES[].img` | 소각로·폐열보일러, 열병합·선박·탱크, 튜브 교체·축로 |
| 열매보일러 세관 사진 | `EXTRA[].img` (`thermal`) | 사업분야 카드, 그 밖에 |
| 더 받을 사례 3곳 | `MORE_WORKS` | 작업사례 맨 아래 |
| PROJECT 띠의 사례 2곳 | `PROJECTS` (`title: null`) | 메인 PROJECT 띠 |
| 이용약관 | `layout.mjs`의 푸터 링크(지금은 `#`) | 푸터 |
| 개인정보처리방침 문구 | `CONTACT.privacyText` (예시 문구) | 상담문의 |

대표 전화번호는 `CO.phone` 한 곳에서 관리합니다. 헤더 전화 버튼, 모바일 하단 상담 바, 상담 띠, 푸터, 상담문의 페이지에 모두 들어갑니다. `null`로 두면 채울 자리로 표시되고, 전화 버튼은 상담문의 페이지로 연결됩니다.

## 사진 넣는 법

사진 자리는 모두 `src/content.mjs`의 데이터로 정합니다.

- `img: null` → 사진 자리(점선 줄무늬 상자)
- `img: 'x.webp', w: 800, h: 600, alt: '사진 설명'` → `assets/img/x.webp`를 보여 줌

1. 사진을 WebP로 바꿔 `assets/img`에 넣습니다. 가로 800~1000px이면 충분합니다.
2. 해당 항목의 `img`에 파일 이름, `w`와 `h`에 실제 픽셀 크기, `alt`에 한국어 설명을 적습니다.
3. 다시 빌드합니다.

예) 소각로 사진: `SERVICES`의 `incinerator` 항목에서 `img: 'svc-incinerator.webp', w: 900, h: 600, alt: '폐열보일러 내부 청소 작업'`

더 받을 사례는 `MORE_WORKS`에 `{ cat: 'tube', title: '○○ 공장 보일러 튜브 교체', where: '울산', img: 'wk-tube.webp', w: 900, h: 600 }`처럼 넣습니다. `cat`은 `boiler`, `incinerator`, `marine`, `tube`, `inspection` 중 하나입니다.

첫 화면 슬라이드 사진은 `HERO.slides`, 서브 페이지 첫 화면 띠 사진은 `BANNERS`에서 바꿉니다. 지금 사진은 원본이 작아(가로 600~966px) 어둡게 덮고 살짝 흐리게 보여 줍니다. 가로 1600px 이상 사진을 받으면 흐림(`site.css`의 `.hero-slide img`, `.sub-hero-bg`의 `filter: blur`)을 빼는 것이 좋습니다.

## 알림 팝업

메인 첫 화면 위에 뜨는 레이어 팝업입니다. `src/content.mjs`의 `POPUPS`에서 관리합니다.

```js
export const POPUPS = [
  { id: 'promo-2026-11', on: true, img: 'popup-banner.webp', w: 700, h: 500, alt: '…', label: '중앙설비산업 안내', href: 'contact/', tel: 'tel:01000000000' }
];
```

- 끄기: `on: false`로 바꾸고 다시 빌드합니다. 모두 꺼지면 팝업이 아예 나오지 않습니다.
- 바꾸기: 그림을 WebP로 `assets/img`에 넣고 `img`, `w`, `h`, `alt`(그림 속 글자를 그대로)를 고칩니다. 내용을 바꾸면 `id`도 바꿔야 '오늘 하루 열지 않기'를 누른 사람에게도 새 팝업이 보입니다.
- 더하기: 항목을 하나 더 넣으면 넓은 화면에서는 나란히, 모바일에서는 위아래로 쌓입니다.
- 그림을 누르면 `href`로 갑니다. 모바일에서는 `tel`이 있으면 전화를 겁니다.
- '오늘 하루 열지 않기'를 고르고 닫으면 그 브라우저에 오늘 자정까지 기록됩니다(`localStorage`의 `jungang-pop-` + id). 저장이 막힌 브라우저에서는 매번 열립니다.
- 넓은 화면에서는 첫 화면 위 왼쪽에 뜨고 뒤를 가리지 않습니다. 모바일에서는 가운데에 뜨고 뒤를 어둡게 합니다. Esc나 '닫기'로 닫힙니다. 자바스크립트가 꺼져 있으면 나오지 않습니다.

## 구조

- `src/content.mjs`: 모든 문구, 연락처, 사진 데이터
- `src/art.mjs`: 아이콘, 수관식 보일러 계통도(소다 보일링 준비 위치), 튜브 단면 그림
- `src/layout.mjs`: 헤더, 모바일 메뉴, 오른쪽 퀵메뉴, 푸터, 모바일 하단 상담 바, 서브 페이지 첫 화면 띠, 사진 자리와 사진 카드
- `src/pages.mjs`: 페이지별 본문
- `build.mjs`: 위 내용으로 HTML을 만듭니다
- `assets/css/site.css`, `assets/js/site.js`: 디자인과 화면 동작
- `assets/img`: 블로그 사진과 마스코트 (WebP)
- `assets/og.png`(공유 이미지 1200×630), `assets/favicon.png`, `assets/apple-touch-icon.png`
- `assets/fonts`: Pretendard (SIL OFL, 라이선스 파일 포함)

첫 화면 사진은 6초마다 넘어가고, 마우스를 올리거나 키보드로 조작하면 멈춥니다. 멈춤 버튼과 화살표, 점으로도 넘길 수 있습니다(화살표 키도 됨). 작업사례의 계통도 약품 흐름은 화면에 보일 때만 움직입니다. '동작 줄이기'를 켠 기기에서는 둘 다 자동으로 움직이지 않습니다.

## 고치는 방법

1. `src/content.mjs`의 문구나 값을 고칩니다.
2. 이 폴더에서 `node build.mjs`를 실행합니다 (Node 18 이상, 설치할 패키지 없음).
3. 만들어진 HTML과 함께 커밋해서 `main`에 올리면 GitHub Pages에 반영됩니다.

시안이라 검색엔진 수집은 막아 두었습니다(`noindex`).
