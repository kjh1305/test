# 이레산업개발 홈페이지 시안

(주)이레산업개발 홈페이지 시안입니다. 주소는 https://kjh1305.github.io/test/ire/ 입니다.

내용은 업체가 준 소개와 블로그 글 목록을 바탕으로 썼습니다. 대표자, 주소, 사업자등록번호, 건설업 등록 정보, 시공 실적과 현장 사진은 '채울 자리'로 표시해 두었습니다. 대표 인사말은 예시 문안입니다.

## 페이지

| 주소 | 내용 |
| --- | --- |
| `/` | 메인: 바닥판, 철골, 벽, 지붕 순서로 지어지는 공장 첫 화면, 짓는 건물 6가지, 직영 시공, 원스톱 과정, 공사비 구성과 땅 확인, 시공사례, 건축 가이드, 상담 지역 |
| `about/` | 회사소개: 대표 인사말(예시), 시공 원칙, 회사 정보, 오시는 길(채울 자리) |
| `business/` | 사업분야: 공장, 창고·물류시설, 근린생활시설, 상가주택·주택, 빌딩·수익형 건물, 증축·대수선, 공사 범위 |
| `projects/` | 시공사례 (현장 사진과 공사 정보를 받으면 채울 자리) |
| `guide/` | 건축 가이드: 블로그 글 24개를 분야별로 걸러 보기 (2026년 11월 9일 기준) |
| `contact/` | 견적문의 폼 (입력 확인만 하고 실제 전송은 없음) |

`contact/?use=factory`처럼 용도를 붙이면 견적문의 폼에서 그 용도가 미리 선택됩니다(`factory`, `warehouse`, `commercial`, `mixed`, `building`).

## 구조

- `src/content.mjs`: 모든 문구
- `src/art.mjs`: 건물 그림(아이소메트릭 SVG), 아이콘
- `src/layout.mjs`: 헤더, 모바일 메뉴, 푸터, 고정 상담 바
- `src/pages.mjs`: 페이지별 본문
- `build.mjs`: 위 내용으로 HTML을 만듭니다
- `assets/css/site.css`, `assets/js/site.js`: 디자인과 화면 동작
- `assets/fonts`: Pretendard, Barlow Condensed (모두 SIL OFL, 라이선스 파일 포함)

## 고치는 방법

1. `src/content.mjs`의 문구를 고칩니다.
2. 이 폴더에서 `node build.mjs`를 실행합니다 (Node 18 이상, 설치할 패키지 없음).
3. 만들어진 HTML과 함께 커밋해서 `main`에 올리면 GitHub Pages에 반영됩니다.

시안이라 검색엔진 수집은 막아 두었습니다(`noindex`).
